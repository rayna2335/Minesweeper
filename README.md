# Minesweeper
This program creates a Minesweeper board using 2D arrays, placing mines randomly and displaying the resulting grid. Each cell either contains a mine ('X') or a number representing the count of adjacent mines.

# Authors
* Rayna Maruyama
* Ayar Maw

## Features
* Randomly place mines on the board.
* Checks each cell and counts adjacent mines.
* Prints the 2D board in a readable format.
* Users can specify board size (rows, columns) and number of mines within limits.

## Tech used
* **language**: C++

## How to play
* Run the main script: `python minesweeper_board_creator.py`
* Enter number of rows, columns, and mines (5-10 each)
* Board will display, showing mines (X) and counts of adjacent mines.
